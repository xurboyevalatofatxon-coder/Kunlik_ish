============================================================
51. PENDING DAY ALGORITHM
============================================================

Latest reviewable date:

today - 1 day

Oldest pending:

the earliest date <= yesterday for which:

- applicable active goals exist;
- not all required results are finalized.

Algorithm:

for dates in ascending order:

    activeGoals = activeGoalsFor(date)

    if activeGoals is empty:
        continue

    results = resultsFor(date)

    if not every activeGoal has finalized result:
        return date

return null
